## Reporting a Vulnerability

Report suspected vulnerabilities privately to `ken@ralphworkflow.com`. Do not
open a public issue before the maintainers have reviewed the report. Include
the affected version, reproduction steps, impact, and any proposed mitigation.

## Supported Versions

Security fixes are published in the latest Ralph Workflow release. Check
[`ralph-workflow/CHANGELOG.md`](ralph-workflow/CHANGELOG.md) to confirm which
release contains a fix.

The implementation requirements live in the canonical
[security policy](docs/ralph-workflow-policy/security-policy.md).
